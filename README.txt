今天吃什麼｜店家專屬客製化建立修正版

本次更新：
- 新增／編輯餐廳、飲料店時，可直接為該店建立專屬客製化選項。
- 每間店各自保存選項，不會把所有店家的甜度、冰量、湯底等選項混在一起。
- 「記一筆」時會顯示該店建立的選項，可複選；同時保留自由輸入當次特殊要求的欄位。
- 新增或刪除選項先在表單草稿內處理，按「儲存店家」才會存入資料。

更新方式：
1. 先備份 GitHub 專案目前的 index.html。
2. 解壓縮 ZIP，將 index.html 覆蓋到 GitHub Pages 專案根目錄。
3. Commit changes，等待網站更新。
4. 若仍顯示舊版，關閉網站再重新開啟。

注意：這份更新包依目前整合試用版修正，尚未在你的手機與既有資料上做完整端到端測試。請先備份。網站仍需手動更新 GitHub。

本次修正：菜單入口預設進入大圖示展示頁，餐點以大圖示、名稱、價格卡片呈現；新增餐點後會自動返回展示頁。需要修改時按「編輯菜單」，按「完成並查看大圖示」返回展示頁。

本次修正：菜單入口預設顯示店家實際上傳的菜單照片，照片以完整寬度展示並可點擊放大；餐點名稱／價格清單收合在次要區塊。只有按「編輯菜單」才進入編輯表單。若店家尚未上傳菜單照片，會明確提示從編輯菜單上傳。

本次修正：同一家店可分多次重複上傳菜單照片，每張都獨立保存且不覆蓋舊照片；每張照片會保留日期、名稱與原始檔名，菜單瀏覽頁可直接查看並點擊放大。若一次選取多張照片，每張都會新增為獨立項目。

本次修正：店家「菜單」按鈕以捕獲階段事件優先打開唯讀菜單照片瀏覽頁；編輯模式新增「返回菜單照片」按鈕；瀏覽頁返回按鈕明確導回店家列表。尚需在實際 GitHub Pages 部署後驗證，並確認已部署的 index.html 確實被覆蓋。

整合修正：店家新增／編輯表單包含「這間店專屬的客製化選項」，可自行新增與移除，儲存店家時保存在該店，記錄消費時可複選。此整合包同時保留菜單照片瀏覽與返回操作修正。請部署後實際確認，更新前先匯出備份。
