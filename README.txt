今天吃什麼｜當下地點功能獨立測試版

本版以「口袋名單規則修正版」為基礎，新增「記一筆」時可選擇取得目前位置：
- 點「取得目前位置」後才會請求瀏覽器定位權限，不會背景追蹤。
- 若成功，緯度／經度會隨該筆消費紀錄保存。
- 可選填地點名稱或地址；不想提供位置也可以直接儲存。
- 此版本不會自動將座標轉成街道地址，需要時請手動填寫。

重要：瀏覽器定位通常需要 HTTPS 或 localhost，且必須由使用者授權。若直接以 file:// 開啟 HTML，部分瀏覽器可能不提供定位功能。建議在 HTTPS 網頁環境測試。

這是獨立測試包，不會更新正式 GitHub Pages 網站。請先備份既有資料再測試。
