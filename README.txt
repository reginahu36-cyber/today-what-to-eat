今天吃什麼｜完整整合更新包
================================

本 ZIP 是網站根目錄的完整更新包，包含：
- index.html：網站頁面與互動程式
- manifest.json：PWA 安裝資訊
- sw.js：Service Worker 快取設定
- README.txt：更新說明

已整合的功能／修正：
1. 店家新增／編輯表單內可建立該店專屬客製化選項，支援新增與移除，儲存後供消費紀錄複選。
2. 菜單照片可分次、多張重複上傳；新增照片不會主動覆蓋舊照片。
3. 菜單入口優先進入照片瀏覽頁；照片可點擊放大；編輯表單需另按「編輯菜單」開啟。
4. 菜單瀏覽頁提供返回店家列表按鈕；編輯頁提供返回菜單照片及完成查看菜單按鈕。
5. 頂部「今天吃什麼」主標題可點擊返回首頁。
6. 保留原型既有店家、分店、營業時間、消費紀錄、主題與資料備份等功能。

更新方式：
1. 先在目前網站匯出資料備份 JSON；請不要刪除瀏覽器網站資料。
2. 解壓縮本 ZIP。
3. 將其中 index.html、manifest.json、sw.js 覆蓋到 GitHub Pages 專案根目錄同名檔案。
4. Commit 變更後，重新整理網站；若仍看到舊畫面，請清除該網站的快取或以無痕視窗確認。
5. 若使用 PWA 安裝版，Service Worker 可能暫時保留舊快取，請關閉後重新開啟，必要時清除該網站快取。

重要提醒：
- 此為整合試用原型，並非正式網站；本次只完成檔案層級整合，尚未在使用者的 GitHub Pages 與 Android 手機上完成端到端驗收。
- 照片以瀏覽器本機資料保存，請定期匯出備份。不要把 ZIP 覆蓋誤認為已部署；仍需自行上傳並 Commit。
