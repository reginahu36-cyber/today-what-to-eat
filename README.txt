今天吃什麼｜手動新增功能更新包

套件內容：
- index.html：整合試用版網站，保留手動新增店家、餐點／菜單項目、消費紀錄與自訂分類等介面。
- manifest.json、sw.js：PWA 安裝資訊與基本快取。

更新方式：
1. 先備份 GitHub 專案目前的檔案。
2. 解壓縮此 ZIP。
3. 將裡面的檔案放到 GitHub Pages 專案根目錄，依提示覆蓋同名檔案。
4. Commit changes，等待 GitHub Pages 更新後重新整理網站。

注意：
- 這是可手動新增資料的整合試用更新包，不包含菜單 OCR 辨識建立。
- 網站資料使用瀏覽器本機儲存；清除網站資料或更換裝置前，請先確認是否有備份功能可用。
- 這個 ZIP 不會自動修改 GitHub 網站；需由你手動上傳更新。
